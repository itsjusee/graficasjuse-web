# portfolio

Web local sin instalaciones ni dependencias.

## Abrir

Abre esta carpeta en Visual Studio Code. Para ver la web, abre `index.html` en tu navegador. También puedes usar la extensión Live Server, si ya la tienes.

## Archivos

- `index.html`: estructura, textos, galería y CV.
- `styles.css`: diseño, cuatro columnas de desktop y adaptación a móvil.
- `app.js`: pestañas y visor de proyectos.

Las dos columnas centrales ocupan el 50 % de la pantalla en desktop. En móvil el contenido ocupa todo el ancho. El selector flotante cambia entre Gráficas y Juse. Los proyectos se abren en un visor con anterior, siguiente y cierre con Escape.
